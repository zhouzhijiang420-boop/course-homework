PART 04

安全需求与安全架构（STPA）

4.1事故与危害定义

事故（Accident）

  • A-1 车辆失控导致碰撞、剐蹭或人员伤害；
  • A-2 车辆发生非预期误动作（误转向 / 误制动 / 误加速）；
  • A-3 故障后车辆无法进入安全状态，滞留危险路面。

系统危害（Hazard）

  • H1 转向能力丧失或转角错误；
  • H2 制动能力丧失或制动力错误；
  • H3 驱动扭矩错误（过量驱动 / 扭矩突增）；
  • H4 故障未被及时检测或未触发降级；
  • H5 冗余切换失败；
  • H6 指令超时 / 丢失后仍沿用旧指令盲目执行。

4.2不安全控制动作（UCA）

以底盘域控为控制器，按 STPA 四类不安全控制动作识别如下：

类别不安全控制动作示例关联危害
未提供所需动作出现故障时未触发降级 / MRC；冗余失效后未由备用链路接管。H4 / H5
提供错误动作转角、扭矩、制动压力或悬架阻尼解算错误；输出超出安全范围的指令。H1 / H2 / H3
动作时机不当指令延迟、过早或过晚执行；高速工况误触发低速泊车策略。H1 / H3
动作持续/停止不当制动未及时解除；降级后未按条件恢复；冗余切换后仍保持主链路输出。H2 / H5

4.3导出的安全需求（安全约束）

由 UCA 与危害反推得到系统必须满足的安全约束，编号 SAFE-xx，纳入 SyRS 并在架构中落实。

编号安全需求 / 约束对应危害
SAFE-01域控须在 ≤ 10 ms 周期内完成传感器、执行器、电源与通信链路的自检与周期诊断。H4
SAFE-02关键转向 / 制动链路须双冗余；单点失效后冗余切换 ≤ 50 ms，且仍能实现最小风险停车。H1 / H2 / H5
SAFE-03制动须双回路独立，单回路失效时仍可产生规定减速度完成安全停车。H2
SAFE-04检测到关键故障后须在限定时间内进入降级或 MRC；禁止带关键故障继续正常行驶。H4 / H1 / H2
SAFE-05指令超时 / 心跳丢失时须进入安全状态（减速或停车），不得沿用最后指令盲目执行。H6
SAFE-06独立安全监控单元（看门狗 / 安全 MCU）监督主计算，超时或异常时强制进入安全状态。H4 / H5
SAFE-07驱动扭矩受 BMS 与高压绝缘状态约束；绝缘或高压故障时切断驱动扭矩。H3
SAFE-08所有故障事件与安全动作须写入可追溯日志，支持事后复盘与责任界定。H4 / H6
SAFE-09冗余切换、降级与 MRC 策略须经故障注入测试验证有效。H5 / H4
SAFE-10OTA 刷写失败或校验不通过时，须回滚至上一安全版本，不得运行未经验证的软件。H4

4.4安全架构措施

冗余 / 监督层级安全架构措施落实安全需求
计算冗余SoC + 锁步安全 MCU 双通道对比；独立看门狗监控主计算，异常触发安全状态。SAFE-06
电源冗余双 12V / 48V 主备电源，主电源失效时备用电源短时供电保障停车动作。SAFE-02
通信冗余CAN FD 双总线 / 以太网双通道，单链路失效后备用链路维持关键指令传输。SAFE-02 / SAFE-05
传感器冗余转角、扭矩、轮速、压力双采样，IMU 冗余；交叉比对识别传感器失效。SAFE-01 / SAFE-02
执行冗余双绕组转向电机、双制动回路与冗余蓄能器；单点执行器失效仍有备用执行通道。SAFE-02 / SAFE-03
状态机监督正常 / 降级 / MRC / 驻车状态机管理模式切换，故障分级触发对应安全动作。SAFE-04 / SAFE-05
软件与版本安全按 ASIL-D 相关要求开发，软件分区隔离；OTA 校验失败自动回滚。SAFE-10
