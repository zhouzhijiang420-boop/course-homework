PART 02

初始系统架构（Initial System Architecture）

1.逻辑架构分层

按「决策 — 计算 — 执行 — 反馈」划分逻辑层次，明确各层职责与交互边界。

L1 上游决策层
自动驾驶大脑（感知 / 决策 / 规划）、高精定位、V2X。输出规划轨迹与运动指令，不参与底盘闭环控制。
L2 域控计算层
底盘域控制器 CDC：SoC + 安全 MCU + 网关；运行运动解算、VDC/ESP、轨迹跟踪与状态监控策略。
L3 执行层
SbW 转向 / BBW 制动 / DbW 驱动 / 主动悬架四大执行子系统，按域控指令完成车轮运动调节。
L4 感知反馈层
传感器组：轮速、转角、扭矩、制动压力、IMU、悬架状态等，向域控闭环反馈车辆状态。

2.物理架构组成

物理架构由作业 1 拆解的六大系统构成，子系统与模块划分保持一致：

系统主要子系统 / 模块
线控转向 SbW前/后轴转向执行电机与传动机构、路感反馈子系统、角度/扭矩传感器组。
线控制动 BBWEHB（主缸模拟器 + 轮缸调压阀）、EMB（四轮卡钳电机 + 驻车执行器）、制动冗余单元（蓄能器 + 隔离阀）。
线控驱动 DbW前/后轴电机控制器与扭矩分配、BMS 能量管理与高压配电、制动能量回收。
主动悬架空气弹簧单元、CDC 可变阻尼减振器、悬架控制器。
底盘域控制器计算平台（SoC + 安全 MCU + 网关）、决策算法（VDC / ESP / 轨迹跟踪）。
冗余安全系统双电源冗余、双总线通信冗余、功能安全监控单元（看门狗 / 独立 MCU）。
架构说明：初始架构以「集中式域控 + 分布式执行器」为基线，预留算力与接口扩展空间；详细子系统树见 作业 1 系统树。
