把驾驶意图，毫秒级、无机械连接地翻译成车轮运动。

线控底盘平台不直接产生决策，它接收自动驾驶大脑下发的规划轨迹，以 ≤20ms 的延迟控制转向、制动、驱动与悬架，保证在城市、高速、泊车等多场景下安全、精准、舒适地执行。

线控转向SbW核心系统

线控转向 SbW：取消方向盘与前轮的机械连接

Steer-by-Wire 由转向执行电机直接控制前轮转角，方向盘仅作为路感反馈输入。支持后轮转向、可变传动比，是自动驾驶轨迹跟踪的执行端。

要点

  • 前后轴均可独立转向
  • 可变传动比，泊车更灵活、高速更稳定
  • 双绕组电机 + 双角度传感器冗余

边界

  • 取消机械连接后必须保证失效可转向
  • 路感标定直接影响驾驶手感
  • 需符合 ISO 26262 ASIL-D
前轴电机后轴电机路感模拟
来源：ISO 26262 · 汽车工程手册
线控制动BBW核心系统

线控制动 BBW：电子液压 + 电子机械双冗余

Brake-by-Wire 取消真空助力，由控制器直接建压。EHB 负责常规制动，EMB 实现四轮独立驻车与紧急制动，双回路独立保证单点失效仍可停车。

要点

  • 踏板感觉模拟器解耦
  • 四轮独立压力调节
  • 与再生制动协同回收能量

边界

  • EMB 尚未大规模量产
  • 紧急制动需独立备用回路
  • 摩擦片磨损需在线监测
EHBEMB双回路
来源：SAE 制动标准 · 博世线控技术资料
线控驱动DbW核心系统

线控驱动 DbW：电机扭矩由控制器直接下发

Drive-by-Wire 取消油门踏板与节气门的机械连接，前后轴驱动电机的扭矩分配由底盘域控制器统一决定，支持扭矩矢量分配与牵引力控制。

要点

  • 前后轴独立扭矩控制
  • 扭矩矢量分配提升过弯性能
  • 与制动能量回收协同

边界

  • 高压系统安全隔离
  • BMS 状态约束最大扭矩
  • 低温下输出能力受限
前轴电机后轴电机BMS
来源：电动汽车工程
主动悬架Active核心系统

主动悬架：实时调节刚度与阻尼

根据自动驾驶预测的路面与工况，主动调整空气弹簧刚度与减振器阻尼，兼顾舒适性与操控性，为高精传感器提供稳定的安装基座。

要点

  • 空气弹簧独立调节车高
  • CDC 阻尼连续可调
  • 预瞄式主动减振

边界

  • 气路系统需密封冗余
  • 功耗高于被动悬架
  • 传感器安装稳定性直接影响感知精度
空气弹簧CDC预瞄控制
来源：车辆悬架设计
底盘域控CDC核心系统

底盘域控制器：统一协调转向/制动/驱动/悬架

Chassis Domain Controller 接收自动驾驶规划轨迹，通过车辆动力学模型计算目标转角、扭矩与制动力，下发给各执行器，并做安全监控。

要点

  • 主 SoC + 安全 MCU 双芯片
  • 车载以太网 + CAN FD 混合通信
  • 内置 VDC / ESP / 轨迹跟踪算法

边界

  • 功能安全需 ASIL-D 认证
  • 与自动驾驶域的接口需标准化
  • OTA 升级需回滚机制
SoCMCU以太网VDC
来源：AUTOSAR 规范
冗余安全Safety核心系统

冗余安全系统：双电源、双总线、双传感器全链路

Redundancy & Safety 在电源、传感器、通信、计算四个层面做全链路冗余，单点故障不影响车辆安全停车，是 L4 级自动驾驶的强制要求。

要点

  • 双 12V/48V 电源冗余
  • CAN FD 双总线独立
  • 关键传感器双采样

边界

  • 成本与重量随冗余上升
  • 故障诊断策略需覆盖边缘场景
  • 降级模式需提前定义
双电源双总线看门狗
来源：ISO 26262 · UL 4600

SYSTEM OF SYSTEMS

所处的上层体系

线控底盘不是孤岛：上接自动驾驶大脑（感知-决策-规划）、车路协同 V2X、高精定位与云端调度平台，下连执行器与传感器，是整车的「手脚」。
