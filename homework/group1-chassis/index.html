核心

线控转向 SbW

Steer-by-Wire · 取消方向盘与前轮的机械连接

由转向执行电机直接控制前轮转角，方向盘仅作为路感反馈输入。支持后轮转向与可变传动比，是自动驾驶轨迹跟踪的直接执行端。

要点

  • 前后轴独立转向，后轮转向提升低速灵活性
  • 可变传动比：泊车低、高速稳
  • 双绕组电机 + 双角度传感器冗余

边界

  • 取消机械连接后必须保证失效可转向
  • 路感标定直接影响驾驶手感
  • 需符合 ISO 26262 ASIL-D
前轴电机后轴电机路感模拟双冗余传感器

线控制动 BBW

Brake-by-Wire

取消真空助力，EHB 常规制动 + EMB 四轮独立制动，双回路独立保证单点失效仍可停车。

要点

  • 踏板感觉解耦
  • 四轮独立调压
  • 回收能量协同

边界

  • EMB 尚未量产
  • 需备用回路
  • 磨损在线监测
EHBEMB双回路

线控驱动 DbW

Drive-by-Wire

前后轴电机扭矩由底盘域控统一下发，支持扭矩矢量分配与牵引力控制。

要点

  • 前后轴独立扭矩
  • 矢量分配过弯
  • 制动能量回收

边界

  • 高压安全隔离
  • BMS 约束扭矩
  • 低温受限
前轴电机后轴电机BMS

主动悬架

Active Suspension

根据预测路面实时调刚度与阻尼，兼顾舒适与操控，为传感器提供稳定基座。

要点

  • 空气弹簧调车高
  • CDC 连续阻尼
  • 预瞄主动减振

边界

  • 气路密封冗余
  • 功耗较高
  • 影响感知精度
空气弹簧CDC预瞄

底盘域控制器

Chassis Domain Controller

接收规划轨迹，用动力学模型算目标转角/扭矩/制动力，下发执行器并监控安全。

要点

  • SoC + 安全 MCU
  • 以太网 + CAN FD
  • VDC/ESP/轨迹

边界

  • ASIL-D 认证
  • 接口标准化
  • OTA 回滚
SoCMCU以太网VDC

冗余安全系统

Redundancy & Safety

电源、传感器、通信、计算四层全链路冗余，单点故障不影响安全停车。

要点

  • 双 12V/48V 电源
  • CAN FD 双总线
  • 传感器双采样

边界

  • 成本重量上升
  • 故障诊断覆盖
  • 降级模式定义

MODULES

最底层：可独立设计的硬件模块

每个子系统拆为可独立选型测试的模块。例如转向执行电机由无刷电机、行星减速器、滚珠丝杠、扭矩传感器、角度编码器、温度传感器、电机驱动 IC 组成。

SYSTEM OF SYSTEMS

所处的上层体系

上接自动驾驶大脑（感知-决策-规划）、V2X 车路协同、高精定位与云端调度，下连执行器与传感器——线控底盘是整车的「手脚」。
